# Who prints Product schema, and how to keep one source

Find the source by searching the saved HTML around each ld+json block: plugins often leave a
comment (`<!-- This site is optimized with the Yoast SEO plugin -->`, `<!-- Rank Math -->`) or
a class/id on the script tag (`class="yoast-schema-graph"`, `class="rank-math-schema"`).

## WooCommerce

| Source | Where it comes from | How to turn it off or fix it |
| --- | --- | --- |
| WooCommerce core | `WC_Structured_Data`, printed in the footer as a Product block | Remove with `remove_action( 'wp_footer', array( WC()->structured_data, 'output_structured_data' ), 10 );` in a small plugin or child theme, only if another plugin outputs complete Product schema |
| Yoast SEO + Yoast WooCommerce SEO | merges product data into the Yoast `@graph` | Keep this, remove the others; set brand/GTIN fields in the product's Yoast tab |
| Rank Math | Schema tab per product, WooCommerce module | Keep or disable per product type in Rank Math > Titles & Meta > Products |
| Theme (many "SEO-ready" themes) | template partial with microdata or JSON-LD | Theme options, or override the template in a child theme |
| Review plugins (e.g. product review add-ons) | add their own Product/aggregateRating | Use their "integrate with WooCommerce schema" option if available |

Prices: WooCommerce core outputs `price` from the active price and `priceValidUntil` as the
end of next year for non-sale products. Check the currency setting and that variable products
output an `AggregateOffer` or a `ProductGroup`.

## Shopify

| Source | Where it comes from | How to fix |
| --- | --- | --- |
| Theme | `{{ product | structured_data }}` (Dawn and other Online Store 2.0 themes) or a hand-written `product-schema` snippet in `main-product.liquid` | Edit a duplicate of the theme first; remove the hand-written snippet if both exist |
| SEO apps | inject their own JSON-LD via app embeds | Choose one: disable the theme snippet or the app's product schema setting |
| Review apps | add `aggregateRating` in a separate block | Prefer the app's option to merge into the theme's Product block |

`structured_data` output follows Shopify's implementation; if it lacks fields you need
(brand, gtin, shipping), replace it with a custom snippet generated by
`scripts/product_schema.py generate` and fill values with Liquid
(`{{ product.selected_or_first_available_variant.price | money_without_currency }}` needs
the decimal separator normalised for stores using comma decimals).

## Headless / custom

Render JSON-LD on the server (not only after client-side JavaScript), from the same data that
renders the visible price, so the two can never disagree.
